# Эмулятор Modbus гибридного инвертора ANENJI 11 кВт

Эмулятор Modbus для гибридного инвертора ANENJI мощностью 11 кВт. Предназначен для имитации телеметрии и рабочих параметров инвертора при разработке, тестировании и интеграции с Home Assistant.

Проект позволяет эмулировать ответы Modbus без физического подключения к инвертору. Это упрощает тестирование сбора данных, настройку датчиков и разработку систем мониторинга с использованием симулированных данных.

## Возможности

- Эмуляция обмена данными по Modbus с гибридным инвертором ANENJI 11 кВт.
- Передача симулируемых параметров инвертора для тестирования и разработки.
- Проверка разбора Modbus-регистров и преобразования полученных значений.
- Разработка и отладка интеграций с Home Assistant без необходимости иметь физический инвертор.
- Возможность расширения для воспроизведения исторических данных за выбранный период.

## Применение

- Разработка и тестирование систем мониторинга инвертора.
- Проверка адресов регистров Modbus и преобразования данных.
- Тестирование сбора данных средствами ESPHome.
- Воспроизведение записанных показаний инвертора для проверки истории и панелей мониторинга Home Assistant.
- Отладка обмена данными и обработки показаний в контролируемых условиях.

## Примечание

Это независимый программный проект, не связанный с ANENJI и не одобренный производителем. Точность эмулируемых данных зависит от реализованной карты регистров и используемых исходных данных.
