# ANENJI 11kW Modbus Emulator

Эмулятор Modbus RTU для гибридного инвертора ANENJI 11 кВт на базе ESP32. Позволяет тестировать чтение регистров и разработку систем мониторинга без подключения к реальному инвертору.

## Возможности

- Modbus RTU Slave, адрес устройства `1`.
- Скорость обмена — `9600`, формат `8N1`.
- Поддержка функции `0x03` — Read Holding Registers.
- Настройка значений регистров через последовательный порт.
- Вывод принятых запросов и отправленных ответов в HEX.
- Предустановленный набор тестовых данных: напряжение, ток, мощность, SOC, параметры PV и энергия.

## Подключение

| Параметр | Значение |
|---|---|
| UART для Modbus | `HardwareSerial(2)` |
| RX | GPIO16 |
| TX | GPIO17 |
| Скорость | 9600 baud |
| Формат | 8N1 |
| Slave ID | 1 |
| UART для команд | USB Serial, 115200 baud |

**Важно:** GPIO16 и GPIO17 — это логические UART RX/TX. Для подключения к физическому интерфейсу RS-232 или RS-485 может потребоваться соответствующий преобразователь уровня. Не подключайте линии RS-232/RS-485 непосредственно к GPIO ESP32.

## Команды

Команды вводятся в Serial Monitor со скоростью `115200` baud. Используйте окончание строки Newline или Both NL & CR.

| Команда | Назначение |
|---|---|
| `GET <address>` | Прочитать значение регистра |
| `SET <address> <value>` | Записать значение регистра |
| `LIST` | Показать все ненулевые регистры |
| `HELP` | Показать справку |

### Примеры

Установить SOC батареи в 75%:

```text
SET 280 75
```

Ответ:

```text
SET 280 = 75 (0x004B)
```

Проверить значение:

```text
GET 280
```

Ответ:

```text
REG 280 = 75 (0x004B)
```

Установить напряжение батареи в 53,2 В. В данном наборе регистров напряжение передаётся в десятых долях вольта:

```text
SET 277 532
```

## Пример Modbus RTU

Запрос на чтение напряжения батареи, регистр `277`, количество регистров — `1`:

```text
01 03 01 15 00 01 94 37
```

Где:

- `01` — адрес Slave.
- `03` — Read Holding Registers.
- `01 15` — начальный адрес `277` в шестнадцатеричном виде.
- `00 01` — количество регистров.
- `94 37` — CRC16 Modbus, младший байт первым.

Если регистр `277` содержит `527`, эмулятор вернёт:

```text
01 03 02 02 0F F8 7D
```

Значение данных `02 0F` соответствует `527`, то есть `52,7 В`.

## Ограничения

- Реализована только функция `0x03`.
- Данные хранятся в оперативной памяти и сбрасываются после перезапуска.
- Значения регистров заданы вручную и сами по себе не отражают реальные измерения.
- Адреса и масштабы регистров соответствуют текущей реализации эмулятора и должны сверяться с картой регистров используемого инвертора.
